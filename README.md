# Independent Easy Loan Portal

A mobile-first independent loan request portal with an English interface, a green/lime theme, one internal application code, and amounts formatted in Somali shillings (SOS).

**Branding notice:** This is an independent project and is not an official WAAFI product, lender, or service. The colour palette is only inspired by the reference screenshots. Do not use WAAFI logos or imply endorsement.

## Run locally

1. Install Node.js 20 or later.
2. Run `npm install`.
3. Configure the environment variables in `render.yaml` as needed.
4. Run `npm start`.

Never ask customers for wallet PINs, passwords, or SMS login OTPs. Code 1 is intended only as an internal reference code for this portal. Loan requests remain subject to real review; submitting a request does not mean a loan is approved or guaranteed.
